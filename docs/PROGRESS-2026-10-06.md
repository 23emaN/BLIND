## 3. ฐานข้อมูล — ตาราง/คอลัมน์ที่เพิ่ม/แก้วันนี้

**ตารางใหม่ (ระบบกิจกรรม):**
- `tbl_activity` — กิจกรรม (ชื่อ, `attribute_id`=หมวดหมู่, วันที่, start/end time, สถานที่, `max_volunteers`, `reserve_count`, รายละเอียด, สถานะ) + **ชั่วโมงจิตอาสา**: `grant_hours`, `hours_per_person`, `hours_count_method`
- `tbl_activity_location` — preset สถานที่ (`location_label`=ชื่อย่อบนปุ่ม, `location_name`=ชื่อเต็มที่เติมลงช่อง)
- `tbl_activity_timeslot` — preset ช่วงเวลา (ชื่อ + start/end)
- `tbl_activity_volunteer` — **การลงทะเบียน + เช็คอิน/เช็คเอาท์**
  - `reg_status` (1=ยืนยันเข้าร่วม, 0=ยกเลิก), `attend_status` (0/1/2)
  - `checked_in_at`, `checkin_method` (1=เช็คอินเอง, 2=เจ้าหน้าที่), `checkin_photo`, `checkin_verify_status` (0=รอตรวจสอบ/1=ยืนยัน/2=ไม่ผ่าน), `checked_out_at`
  - `hours_credited` (ชม.จิตอาสา → ใช้ออกใบรับรอง), `remark`
- `tbl_volunteer_skill` — ความถนัดของจิตอาสา (ตารางแยกเฉพาะ: `volunteer_id` ↔ `attribute_id` type 2)

**แก้ตารางเดิม:**
- `tbl_attribute` — เพิ่ม `attribute_icon`, `attribute_desc` (ใช้กับหมวดหมู่กิจกรรม type 1)
- **รวมหมวดหมู่กิจกรรม เข้ากับ `tbl_attribute` type 1** (ไม่มีตารางหมวดหมู่แยก — รอคนทำเว็บประเมินยืนยัน)

**ไฟล์ SQL ใน `sql/`:** `activity_schema.sql`, `attribute_categories.sql`, `volunteer_skill.sql`, `update_location.sql`, `update_activity_hours.sql`

> ⚠️ **charset:** ตอนแรกภาษาไทยเพี้ยน (mojibake) เพราะรัน mysql CLI ไม่ได้ตั้ง utf8mb4 — แก้แล้ว ทุก seed/comment สะอาด
> **import/export ต้องใช้ `--default-character-set=utf8mb4` เสมอ** และมี `SET NAMES utf8mb4;` ต้นไฟล์
